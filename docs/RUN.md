## Quick start

## Frontend
From:
`E:\kolam-2`

```bash
npm install
npm run dev
```

Frontend URL:
`http://localhost:3000`

## Backend
From:
`E:\kolam-2\backend`

```bash
pip install -r requirements.txt
python main.py
```

Backend URL:
`http://localhost:8000`

